# webapp — интерфейс (первые куски)

Первый реальный кусок UI под макет-референс (workbench класса CAE): **вьюпорт геометрии**,
рисующий НАСТОЯЩУЮ треугольную сетку решателя, а не стилизацию.

## Файлы
- `geometry_viewer_template.html` — шаблон вьюпорта (CAD-холст: координатная сетка в мм,
  зум колесом, панорама, регионы по материалам, каркас, оси намагничивания). Плейсхолдер
  `__SCENE__` заменяется на JSON сцены.
- `make_viewer.py` — экспортирует реальную сцену (`Problem2D → problem_to_scene`) и внедряет
  её в шаблон → самодостаточный `geometry_viewer.html`.
- `geometry_viewer.html` — сгенерированный вьюпорт (открыть в браузере).

## Сборка
```
python -m webapp.make_viewer      # нужен gmsh
```

## Что дальше (по кускам)
Вьюпорт → назначение материалов/токов объектам → запрос результата (точка/линия/окружность)
→ решение по кнопке (бэкенд). Данные всегда из `magcore` (модель задачи `Problem2D`), UI —
тонкая обёртка. Согласованный облик — макет-артефакт (см. историю).
