# Пилот magnet-platform

Приложение для запуска расчётов, **визуализации** и **ручной проверки** результатов
верифицированного 2D-ядра (`magcore`).

## Граница (важно)

Пилот **только импортирует** `magcore` и никогда его не меняет. Верифицированное ядро
(435 тестов) неприкосновенно. Удаление папки `pilot/` не затрагивает ядро.
Переиспользуемая физика (момент/ЭДС/потери/мешер) по мере созревания поднимается в
`magcore` аддитивно, с собственными оракулами; здесь — только приложение.

## Запуск демо

```bash
python -m pilot.examples.demo_magneto_thermal
```

Считает связку магнит-тепло-демаг для NdFeB и SmCo, сохраняет графики в `pilot/output/`
и печатает числовой отчёт (+ файл `output/report.txt`):

- `B_field.png` — поле B (модуль + направление);
- `temperature.png` — температурное поле;
- `demag_ndfeb.png`, `demag_smco.png` — карты риска размагничивания (за коленом = красным);
- `material_comparison.png` — T-стойкость NdFeB vs SmCo (при какой T каждый уходит за колено);
- в отчёте — **оракул доверия** (намагниченный цилиндр H_in = −0.5 аналитически), чтобы
  убедиться, что решатель совпадает с точным решением, прежде чем доверять прикладным числам.

## Структура

```
pilot/
  viz.py            графики полей на треуг. сетке (matplotlib → PNG)
  examples/         запускаемые демо-сценарии
  output/           генерируемые PNG (git-ignored)
  tests/            smoke-тесты пилота
```
