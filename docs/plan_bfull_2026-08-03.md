# План реализации B-full (по кускам, с оракулами)

> Полная тепловая модель ядра К6′: собственные потери магнита/ротора + сталь + Тейлор-зазор + дифф. ГУ + режим напряжения. Постановка — `math/coupled_problem.md`; параметры — `math/bfull_parameters.md`; методология — `coupled_problem.md §12`.
> **Кодим ТОЛЬКО после гейта научрука** (`docs/gate_package_2026-08-03.md`). Каждый кусок — со своим оракулом (стоячий принцип: качество ≥ скорость).

---

## Куски

### P-B0 · Пред-регистрация + сценарий-конфиг `[~0.5 дня]`
- **Что:** зашить таблицу `bfull_parameters.md` в конфиг сценария; dt≤0.5, T_cap. Артефакт пред-регистрации (§12).
- **Оракул:** конфиг валидируется; условия зафиксированы ДО прогонов.
- **Вход:** все параметры. **Зависимость:** —

### P-B1 · Дифференцированные ГУ (h_in ≠ h_out, статор→рама) `[~2–3 дня]`
- **Что:** рефактор `thermal.py::assemble_robin_boundary` → per-edge (h, T_ref); тегирование граничных рёбер внутр.(статор→рама)/наружн.(ротор→среда) по радиусу; внутр. = сильный h_in / Дирихле T_frame.
- **Оракул:** энергобаланс точен; h_in=h_out воспроизводит старое (регрессия); статор охлаждается в раму → медь НЕ разгоняется искусственно при умеренной нагрузке (снимает артефакт калибровки).
- **Вход:** h_out, h_in/T_frame. **Зависимость:** P-B0.

### P-B2 · Тейлор-зазор k_eff(n) `[~2–3 дня]`
- **Что:** Ta из геометрии+скорости → Nu(Ta) (3 режима) → k_eff для ячеек зазора; заменить k_gap=const (сейчас 0.5, завышен ~8–18×).
- **Оракул:** n=0 → Nu→2 → k_eff=k_air (статика); монотонность по n; сверка порога вихрей ~1740 об/мин и Nu(7000)≈4.7 с Howey.
- **Вход:** свойства воздуха, n. **Зависимость:** P-B0.

### P-B3 · Потери в стали (статор+ротор) Штейнмец из rotor-sweep `[~3–4 дня]`
- **Что:** `rotor_sweep` → B(θ) по ячейкам при рабочем токе/скорости → амплитуда/гармоники B → Штейнмец p_Fe(B,f) с коэфф. M270 → карта q_Fe → в `extra_loss`. Переиспользовать `iron_loss.py`.
- **Оракул:** суммарные потери стали vs Cogent Вт/кг при (B,f); масштаб по f и B; ноль при f=0.
- **Вход:** Штейнмец M270, ρ_steel, плотность, n. **Зависимость:** P-B0.

### P-B4 · Вихревые в магните из rotor-sweep dB/dt `[~4–6 дней, сложнейший]`
- **Что:** `rotor_sweep` → dB/dt по ячейкам магнита → q_pm = σ_pm(T)·⟨|∂ₜB|²⟩·g(N_seg) (формула вихревых в проводящей пластине с сегментацией). Новый модуль.
- **Оракул:** аналитика вихревых в пластине в синус. поле $P=\sigma(2\pi f)^2B^2w^2/24$ /объём; сегментация ∝1/N²; отношение SmCo/NdFeB = отношение σ (~1.6); ноль при f=0.
- **Вход:** σ_pm(T), N_seg, размеры магнита, n. **Зависимость:** P-B0.

### P-B5 · Интеграция источников в coupled_transient (заморожены за шаг) `[~1–2 дня]`
- **Что:** предвычислить q_Fe+q_pm при рабочей точке → `extra_loss` callable; обновление при заметном изменении тока/состояния.
- **Оракул:** энергобаланс включает новые источники; суммарные потери = медь+сталь+магнит согласованы.
- **Вход:** выходы P-B3, P-B4. **Зависимость:** P-B3, P-B4.

### P-B6 · Режим напряжения (деградация характеристик) `[~1–2 дня]`
- **Что:** пост-проц: I=(U−E)/R(T), E=K_e(T,r)·ω, момент=K_t·I, КПД; отчёт о падении момента/КПД по траектории (R(T)↑ + K_t↓).
- **Оракул:** холодный/номинал воспроизводит паспортную точку; монотонная деградация с T и демагом.
- **Вход:** U, kV/K_e, R (геометрия), n. **Зависимость:** P-B0 (незав. от P-B1..5, пост-проц).

### P-B7 · Пред-регистрированный сценарий + верификация + чувствительность `[~2–3 дня]`
- **Что:** собрать: dt≤0.5, T_cap, горячая среда, worst-case d, **полный свип нагрузки, одинаковый обоим материалам**; прогнать оракулы §10 (dt-сходимость теперь ОБЯЗАНА пройти); свипы чувствительности (§12: h, коэфф. потерь, σ_pm, N_seg, ШИМ).
- **Оракул:** dt-сходимость <2°C; все оракулы §10 зелёные; полоса неопределённости crossover задокументирована.
- **Вход:** всё. **Зависимость:** P-B1..P-B6. → далее перегон харвеста `harvest_paper1.py`.

## Последовательность и зависимости
```
P-B0
 ├─ P-B1 (ГУ) ─────────────┐
 ├─ P-B2 (Тейлор-зазор) ───┤
 ├─ P-B3 (сталь) ──┐       │
 ├─ P-B4 (магнит) ─┴ P-B5 ─┤
 └─ P-B6 (напряжение) ─────┴─ P-B7 (сценарий+верификация+чувствительность) → харвест
```
P-B1, P-B2, P-B3, P-B4, P-B6 — независимы после P-B0 (можно параллелить/чередовать); P-B5 ждёт P-B3+P-B4; P-B7 ждёт всех.

## Оценка сроков
Сумма ~**1.5–2.5 недели** (P-B4 — свинг: вихревые магнита сложнее всего). Каждый кусок закрывается своим оракулом до перехода к следующему.

## Что БЛОКИРУЕТ старт (нужно от Sergey — см. `bfull_parameters.md §4`)
Критично для запуска: **номинальный ток/мощность** (диапазон свипа) и **U/kV** (режим напряжения). Желательно: **N_seg** (сегментация), **T_frame**, worst-case **среда/охлаждение**. Материальные константы (сталь, σ магнитов, воздух, Тейлор) — **собраны и источникованы** (`bfull_parameters.md §1–3`).
