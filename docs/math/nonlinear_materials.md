## 1. Что нелинейно, что анизотропно-линейно

- **Сталь** (M270-35A, спинка/зубцы): **нелинейная изотропная**, насыщение. `H = ν(|B|) B`.
- **Магнит** (NdFeB N42SH), reversible recoil: **линейный, но АНИЗОТРОПНЫЙ** (ось лёгкого намагничивания `e`) + температурно-параметрический (`ν_∥≠ν_⊥`, `B_r(T)`).
- **Магнит, колено/необратимость:** **нелинейно + история-зависимо** (необратимое размагничивание ниже колена).

⇒ Нелинейность решателя гонит **сталь** (и активное колено магнита); recoil магнита линеен.

**Важно (структура связанной задачи):** внешняя BEM-область (воздух) линейна и неизменна. Нелинейна только внутренняя форма `a(A,v)` ⇒ по итерациям пересобирается **только блок `A_FF`**; операторы `V/K/W`, `B_FΓ`, калибровка, знаки — те же (новизна 1 не трогается).

## 2. Релуктивность, дифференциальная релуктивность, касательный тензор

`B = |curl A|` (модуль), `B̂ = curl A/B`.
- **Хордовая:** `ν(B) = H(B)/B`.
- **Дифференциальная:** `ν_d(B) = dH/dB`.
- **Касательный тензор** (линеаризация `H = ν(B)·curl A` по `curl A`):

$$\boxed{\;\nu_t \;=\; \nu\,(I - \hat B\hat B^{T}) \;+\; \nu_d\,\hat B\hat B^{T}\;}\qquad (\nu_d = \nu + B\,\nu'(B)).$$

Вдоль `B` — дифференциальная `ν_d`; поперёк — хордовая `ν`. **Даже изотропный материал даёт анизотропный касательный** — это и есть «tangent μ_eff-тензор». Собств. значения `ν_t`: `ν` (кратность 2) и `ν_d` (вдоль `B`).
- **Физ. границы (сталь):** монотонная B–H (`dH/dB>0`) ⇒ `0 < ν_min ≤ ν, ν_d ≤ ν_max = 1/μ₀ < ∞`. ✅ (нужно для коэрцитивности, §6).

## 3. Нелинейная сталь `ν(B)`

- B–H из данных **M270-35A** (табличная, монотонная, насыщение). Хранение: монотонные узлы `(H_i,B_i)`; интерполяция с сохранением монотонности (PCHIP/моноклип); экстраполяция в насыщении `B → μ₀H + B_sat` (наклон `→ μ₀`, `ν→1/μ₀`).
- Из таблицы: `ν(B)`, `ν_d(B)`; численно гарантировать `ν_d>0`.
- Низкое `B`: `μ_r∼10³–10⁴` ⇒ `ν` мала; высокое `B`: `ν→1/μ₀`. Диапазон `[ν_min,ν_max]` ограничен и отделён от 0/∞.

**Точный контракт реализации (`magcore/domain/steel_curves.py`, чистый NumPy):**
- `ν(B) = H(B)/B` (хорда, для Picard); `ν_d(B) = dH/dB` (дифференциальная, для Newton/§2). `H(B)` — кусочно-линейная инверсия таблицы `B→H`.
- Узел `(0,0)` обязателен ⇒ предел `ν(B→0) = ν_d(0) = H_1/B_1` **точно** (первый сегмент проходит через начало координат).
- Насыщение `B>B_max`: `H(B) = H_max + (B−B_max)/μ₀` ⇒ `ν_d=1/μ₀`, `ν→1/μ₀` (наклон μ₀, как у вакуума).
- Физ-ограничение данных: дифф. проницаемость `μ_diff = dB/dH ≥ μ₀` ⇔ наклон таблицы `dH/dB ≤ 1/μ₀` (валидируется ⇒ `ν_d ≤ ν_max = 1/μ₀`, нужно для коэрцитивности §6).
- Данные **M270-35A — представительные** (типовая форма нонориент. стали 0.35 мм); сверить с офиц. datasheet (Cogent/EN 10106) до количественного использования. Класс кривая-агностик: замена данных тривиальна. ✅

## 4. Анизотропный температурно-зависимый магнит `B(H,T)`

Ось `e` (`|e|=1`); `B = B_∥e + B_⊥`, `H = H_∥e + H_⊥`.

**Recoil (обратимая, `H_∥ ≥ H_k(T)`):**
$$B_\parallel = B_r(T) + \mu_0\mu_{rec}(T)\,H_\parallel,\qquad B_\perp = \mu_0\mu_\perp(T)\,H_\perp.$$
⇒ в A-форме `H = ν_\parallel(B_\parallel - B_r)\,e + ν_\perp B_\perp`, `ν_\parallel = 1/(\mu_0\mu_{rec})`, `ν_\perp = 1/(\mu_0\mu_\perp)`. Анизотропный тензор и источник:
$$\nu_{mag} = \nu_\perp (I - ee^{T}) + \nu_\parallel ee^{T},\qquad \text{источник } = \nu_\parallel B_r(T)\,e.$$
(При `μ_⊥=μ_rec` сводится к изотропному `A-3` magnetization RHS с `B_r e`.)

**Температура (NdFeB):** `B_r(T) = B_{r0}[1+α_B(T-T_0)]` (`α_B≈-0.0012/K`); `H_{cj}(T)=H_{cj0}[1+α_H(T-T_0)]` (`α_H≈-0.006/K`); колено `H_k(T)` растёт к нулю с ростом `T` (риск размагничивания на форсаже).

**Колено + необратимость (⚠ модель — §9.1):** при `H_∥ < H_k(T)` точка уходит на главную (нелинейную) intrinsic-кривую; при восстановлении — новая recoil-линия с `B_r' < B_r`. Состояние: трекать `H_{∥,min}` по нагрузке; если `< H_k(T)` ⇒ необратимая потеря `ΔB_r = B_r − B_r'`, где `B_r'` определяется точкой схода с главной кривой.

**Risk-map (deliverable новизны 2):** маржа `m = H_∥ − H_k(T)` (или эквивалентно по `B`); `m < 0` ⇒ элемент размагничен. Для нагрузочного цикла/угла — худшее по углам ротора (фаза Ca).

**Точный контракт реализации (curve-driven, `magcore/domain/{magnet_curves,magnet_model}.py`, чистый NumPy):**

Материал задаётся **кривой размагничивания** `B(H)` (2-й квадрант), а не россыпью скаляров. Кривая строится из 4 даташит-параметров `(B_r, H_cB, H_k, H_cJ)` в форме **C¹** — фабрика `demag_curve_from_datasheet` (+ CGS-обёртка `_cgs` для Гс/кЭ):
- `μ_rec = B_r/(μ₀ H_cB)`; интринзик-наклон `s_J = μ₀(μ_rec−1)`;
- интринзик `J(H)`: прямая `J=B_r+s_J·H` выше колена `H_k=−|H_k|`; ниже — **парабола** `aH²+bH+c`, **касательная** к прямой в колене (C¹) и `J(−|H_cJ|)=0`; коэффициенты — замкнутая форма (`a=−[J_k−s_J·d]/d²`, `d=H_cj−H_k`, `b=s_J−2a·H_k`, `c=J_k−a·H_k²−b·H_k`);
- нормальная кривая `B(H)=J(H)+μ₀H` — выше колена это recoil `B_r+μ₀μ_rec·H` (ноль при `−H_cB`), ниже колена уходит в минус (нормально для высококоэрцитивных).
> ✅ Совпало с независимой инженерной Excel-методикой (прямая + касательная парабола, 2 коэф.). Кросс-проверка в тесте: `J(колено)≈1.0043 Тл` = `10043 Гс` шаблона.

Температура (конвенция методики, коэф. в `%/°C`, `ΔT=T−T0`): масштабирование кривой **двумя** коэффициентами —
`b(T)=1−α_Br·ΔT/100` (ось B), `h(T)=1−γ_Hc·ΔT/100` (ось H). Эвал на T-кривой: `B^maj_T(H)=b(T)·B^{maj}_{T0}(H/h(T))`. ⇒ `B_r(T)=b(T)·B_r0`, колено `H_k(T)=h(T)·H_k0`. (Разные `α_Br` и `γ_Hc` — по марке.)

Состояние (на ячейку): `H_min` — наименьшее достигнутое `H_∥`.
Эффективная ремнантность — **обобщённая форма (любая кривая)**: новый recoil через «худшую точку» на главной кривой, наклон `μ₀μ_rec`:
$$\boxed{\;B_r^{eff}(H_{min},T) = B^{maj}_T(H_{min}) - \mu_0\mu_{rec}\,H_{min}\;}$$
Выше колена `B^maj_T` = recoil-прямая ⇒ `B_r^eff=B_r(T)` (потерь нет, **проверка колена не нужна**); ниже — падает круче ⇒ `B_r^eff<B_r(T)`. (Билинейная `ΔB_r=μ₀(μ_knee−μ_rec)max(0,H_k−H_min)` — частный случай.)

Тензор (recoil, постоянный): `ν_mag=ν_⊥(I−ee^T)+ν_∥ ee^T`, `ν_∥=1/(μ₀μ_rec)`, `ν_⊥=1/(μ₀μ_⊥)`. FEM-источник (A-3): `B_r^eff·e`.
Рабочая точка: `H_∥=(B·e − B_r^eff)/(μ₀μ_rec)`; risk-margin `m=H_∥−H_k(T)`.

**Recoil-после-T — field-resolved (НЕ lumped):** `H_∥` и «худшая точка» считаются по полю **на каждой ячейке** (а не через одну нагрузочную линию, как в lumped Excel-методике) ⇒ неоднородное размагничивание у краёв полюса воспроизводится естественно; lumped load-line construction не используем. Цикл: solve → `H_∥` по ячейкам → `H_min←min` → пересчёт `B_r^eff` → re-solve (Picard по состоянию) до стабилизации; худшее по углу/`T`.

Единицы: `1 кЭ=1e6/(4π) А/м ≈ 79.577 кА/м`, `1 Гс=1e-4 Тл`. Данные марок — представительные, сверить с datasheet. Excel-кейс (Br=11114 Гс, HcB=10.4, Hk=15.6, HcJ=28.4 кЭ, T=180°C) — верификационный тест.

## 5. Нелинейная связанная слабая форма + Picard

Внутренняя форма по материалам ячеек:
$$a(A,v;A) = \int_{\Omega_{steel}} \nu(|\!\operatorname{curl}A|)\,\operatorname{curl}A\cdot\operatorname{curl}v \;+\; \int_{\Omega_{mag}} \nu_{mag}\operatorname{curl}A\cdot\operatorname{curl}v,$$
правая часть магнита `∫_{Ω_mag} ν_∥ B_r(T)\,e·curl v` (= A-3 с тензорным `ν`). Калибровка, `B_FΓ`, внешний блок — без изменений.

- **Picard (фиксированная точка):** шаг `k`: заморозить `ν^k = ν(|B^k|)` (сталь) и активные `B_r^k`/состояние колена (магнит) → собрать линейный `A_FF^k` → решить связанную систему (решатель из `hybrid/solver.py`) → `B^{k+1}=curl A^{k+1}` → обновить. Критерий: `‖B^{k+1}−B^k‖/‖B^k‖ < tol`. Под-релаксация `B^{k+1}←(1−ω)B^k+ωB^{k+1}` при «дрожании».
- **Newton:** касательный `A_FF` с `ν_t` (§2); квадратичная сходимость; **нужен для adjoint (фаза E)** (та же касательная матрица).

## 6. Корректность (надзор; уточняет ROADMAP §5.1) ✅

- **Монотонность.** Оператор `A ↦ curl(ν(|curl A|)curl A)` монотонен (B–H монотонна, `ν_t ⪰ ν_min I > 0`) ⇒ по **Браудеру–Минти** нелинейная задача имеет единственное решение.
- **inf-sup при нелинейности (точная формулировка).** На каждом шаге Picard/Newton рассматривается **линейная касательная** седловая задача с `ν_t∈[ν_min,ν_max]`. Равномерная коэрцитивность `a_t(v,v)=∫ν_t curl v·curl v ≥ ν_min‖curl v‖²` на дискретно-соленоидальном ядре + inf-sup пары Неделек×P1 ⇒ корректность и квазиоптимальность **шага**. Формулировать ИМЕННО так: «inf-sup устойчивость касательной задачи на каждом шаге», НЕ «inf-sup нелинейной задачи».
- **⚠ Негладкость колена.** На колене `ν_mag`/`B_r(·)` не `C¹` ⇒ классического IFT-adjoint (фаза E) и гладких TR-градиентов (новизна 4) НЕТ. Решить (§9.2): (а) **регуляризованная** (сглаженная `C¹`) `B(H,T)` — сохраняет IFT-adjoint, с контролем погрешности сглаживания; (б) semismooth Newton / субградиент.

## 7. Детект колена и risk-map (deliverable новизны 2)

Для каждой магнитной ячейки после решения: `H_∥ = (ν_∥)(B_∥ − B_r)`... → сравнить с `H_k(T)`; `margin = H_∥ − H_k(T)`. Карта `margin<0` = размагниченные зоны. Полный (необратимый) режим: цикл «решить → найти ушедшие за колено → понизить их `B_r` → пере-решить» (Picard по состоянию колена) до стабилизации. Для рабочих сценариев — худшее по углу ротора / по T форсажа.

## 9. Решения для научрука (⚠)

> **Research 2026-06-05 (`docs/novelty/prior_art_map.md`):** связка зафиксирована — **A3** (п.1, Ruoho intrinsic+recoil+worst-point) + **B1/регуляризация C¹** (п.2) + **Picard→Newton** (п.3). Важно: регуляризация сама по себе **НЕ новизна** (Krenn–Gangl 2024 уже сглаживают demag-ограничение); новизна — *бюджет смещения* + *conformal-маржа* (точка 4) + *интеграция в открытый FEM/BEM*. B2 (semismooth) занят Эггером 2025 (forward-only); B3 (adjoint пластичности) строг, но дорог и из механики. Различать **две негладкости**: конституционную (колено) vs оптимизационную (max-ограничение).

1. **Модель колена/необратимости:** главная intrinsic-кривая + recoil-ветви, или упрощённая «срез `B_r` при заходе за колено»? Источник данных колена для **N42SH** при рабочих `T` (даташит/литература).
2. **Сглаживание колена** (регуляризация `C¹`) vs semismooth — для adjoint фазы E. **Рекомендация:** регуляризованная `B(H,T)` (сохраняет IFT-adjoint), погрешность сглаживания контролируется и `→0`.
3. **Picard vs Newton** по умолчанию для forward; под-релаксация. (Newton нужен в любом случае для фазы E.)
4. **Анизотропия recoil:** нужен ли `μ_⊥≠μ_rec` (для N42SH часто `μ_⊥≈μ_rec≈1.05`), или изотропный recoil достаточен на первом этапе.
