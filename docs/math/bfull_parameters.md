## 3. Воздух зазора + Тейлор–Куэтт (k_eff зазора)

Воздух (1 атм): k_air 0.027 (50°) → 0.031 (100°) Вт/(м·К); ν 1.8–2.3×10⁻⁵ м²/с; Pr 0.70. (Incropera/Cengel.)

Модель (Howey–Childs–Holmes 2010, IEEE TIE, DOI 10.1109/TIE.2010.2100337):
- $\mathrm{Ta}_m=\Omega\,r_m^{0.5}(b{-}a)^{1.5}/\nu$; критич. $\mathrm{Ta}_{cr}=41.19$.
- Nu по $\mathrm{Ta}^2/F_g^2$: <1700 → Nu≈2 (кондукция); 1700–10⁴ → $0.128(\mathrm{Ta}^2/F_g^2)^{0.367}$; >10⁴ → $0.409(\mathrm{Ta}^2/F_g^2)^{0.241}$.
- **$k_{eff}=\mathrm{Nu}\cdot k_{air}/2$** (D_h=2g; при Nu=2 → k_eff=k_air).

Расчёт для нашего мотора (g=1мм, r_m≈22.5мм):
- **вихри Тейлора с ~1740 об/мин**; ниже — чистая кондукция.
- **на 7000 об/мин:** Nu≈4.7 → **k_eff≈0.065 Вт/(м·К)**.
- режимы: кондукция <1740; ламин.-вихри 1740–4300; турбул. >4300 об/мин ⇒ k_eff = f(Ω,T), НЕ константа.

**🔴 ВАЖНАЯ ПОПРАВКА:** текущий представительный $k_{gap}=0.5$ **завышен в ~8–18×** (реальный k_eff 0.027 статич. → 0.065 @7000). Значит зазор изолирует магнит **сильнее**, чем в калибровке ⇒ ещё меньше тепла меди доходит до магнита ⇒ **усиливает вывод A+B-full** (магнит греют своя нагрузка + среда, не медь).
