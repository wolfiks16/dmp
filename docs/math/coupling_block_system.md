# B-2. Дискретная симметричная блок-система FEM/BEM (Costabel)

> **Назначение.** Формализовать — ДО кодирования — точную дискретную симметричную блок-систему новизны (1): соотношения скачков → внешние уравнения Кальдерона `(E1)/(E2)` → дискретные операторные блоки → симметричная сборка → процедура «пиннинга» знаков тестами. Продолжает B-1 (`coupling.md`), опирается на `formulation_bounded.md`.
>
> **Статус:** черновик для согласования с научруком. Всё, что выведено строго, отмечено ✅; единственный незакреплённый пункт (точная знаковая комбинация во внешнем замыкании) явно помечен ⚠ и снабжён тест-процедурой пиннинга. **Знаки не хардкодятся наугад.**

## 1. Соглашения (фиксируются раз и навсегда)

- `n` — единичная нормаль на `Γ=∂Ω`, **наружу из `Ω`** (в `Ω^c`).
- Операторы Лапласа, ядро `G(x,y)=1/(4π|x−y|)`:
  - `V` — однослойный; `K` — двойнослойный (ядро `∂_{n_y}G`); `K'=Kᵀ` — сопряжённый (`∂_{n_x}G`); `W` — гиперсингулярный.
- **Соотношения скачков** (подход изнутри `−`, снаружи `+`; конвенция §4 `coupling.md`):
  - `γ^∓(Vφ) = Vφ` (непрерывен);
  - `γ^∓(Dφ) = (∓½I + K)φ` (внутр. `−½`, внеш. `+½`);
  - `∂_n^∓(Vφ) = (±½I + K')φ` (внутр. `+½`, внеш. `−½`);
  - `∂_n^∓(Dφ) = −Wφ` (непрерывен).

  где `D` — потенциал двойного слоя. ✅ Согласовано с `transmission_solve.py` и с проверкой `Σ_m K[f,m]=−A_f/2` (см. §7).

## 2. Тождества Кальдерона: внутренние и внешние

**Внутренние** (`u` гармонична в `Ω`, `t=∂_n u`, `n` наружу), из §1 + формулы Грина `u = Vt − Du` в `Ω`:

$$\textbf{(I1)}\quad V t = (\tfrac12 I + K)\,u_\Gamma, \qquad \textbf{(I2)}\quad W u_\Gamma = (\tfrac12 I - K')\,t.$$

**Внешние** (`ψ` гармонична в `Ω^c`, убывание; `λ=∂_nψ` по `n` наружу из `Ω`), из представления `ψ = Dψ_Γ − Vλ` в `Ω^c` и внешних скачков `+½`:

$$\textbf{(E1)}\quad V\lambda = (K - \tfrac12 I)\,\psi_\Gamma, \qquad \textbf{(E2)}\quad W\psi_\Gamma = -(\tfrac12 I + K')\,\lambda.$$

> Вывод (E1): `ψ_Γ = γ^+(Dψ_Γ) − γ^+(Vλ) = (½I+K)ψ_Γ − Vλ ⟹ Vλ = (K−½I)ψ_Γ`.
> Вывод (E2): `λ = ∂_n^+(Dψ_Γ) − ∂_n^+(Vλ) = −Wψ_Γ − (−½I+K')λ ⟹ (½I+K')λ = −Wψ_Γ`.

**Тождества Кальдерона** (проектор `P=[[½I−K, V],[W, ½I+K']]`, `P²=P`) — основа знаковых тестов:

$$V W = \tfrac14 I - K^2,\quad W V = \tfrac14 I - K'^2,\quad V K' = K V,\quad K' W = W K.$$

## 4. Дискретные пространства и операторные блоки

Неизвестные: `A∈V_h` (Неделек), `p∈Q_h` (P1, калибровка), `ψ∈Λ_h` (**P1-вершины** Γ), `λ∈Σ_h` (**P0-грани** Γ). Тесты `v,q,ξ,μ`.

| Блок | Билинейная форма | Простр. | Размер | Статус |
|---|---|---|---|---|
| `A_FF` | внутр. седло `[[K,G],[Gᵀ,0]]` | Néd×P1 | sparse | ✅ фаза A |
| `B_FΓ` | `⟨ψ, curl v·n⟩_Γ` | Néd×P1(Γ) | sparse | ✅ `hybrid/assembly` (`B·1=0`) |
| `V_BB` | `⟨Vλ, μ⟩_Γ` | P0×P0 | dense | ✅ `assemble_single_layer_p0p0_full`, SPD |
| `W_ΓΓ` | `⟨Wψ, ξ⟩_Γ` | P1×P1 | dense | ✅ `assemble_hypersingular_maue` (Мауэ; `⪰0`, `W·1=0`) |
| `K_gal` | `⟨Kψ, μ⟩_Γ` | P0×P1 | dense | ✅ `assemble_double_layer_galerkin`; `K'=K_galᵀ` |
| `M_PG` | `⟨ψ, μ⟩_Γ` (масса/дуальность, = «`½I`») | P1×P0 | sparse | ⛔ TODO |

> **`M_PG` тривиальна:** `∫_{T_f} λ_m^{P1} dS = A_f/3` для каждой из 3 вершин `m` грани `f`. Т.е. `M_PG[m,f]=A_f/3`, иначе 0. Проверка: сумма по вершинам грани `Σ_m M_PG[m,f]=A_f`; сумма по всем `=` площадь Γ.

Из этих блоков собираются комбинации `(½I±K)`, `(½I±K')`:

$$C_{ΓB} \;=\; \tfrac12 M_{PG} \;\pm\; K_{gal}^{T}\quad(\text{блок }(\tfrac12 I\pm K')),\qquad M_{ΓΓ} \;=\; \mu_0\,W_{ΓΓ}\ (+\ \text{возможные }K\text{-члены}).$$

## 5. Симметричная блок-система (структура; знак внешнего блока ИСПРАВЛЕН 2026-06-03)

$$
\begin{bmatrix}
A_{FF} & B_{FΓ} & 0\\
B_{FΓ}^{T} & -\mu_0 W & +C_{ΓB}\\
0 & +C_{ΓB}^{T} & +V_{BB}
\end{bmatrix}
\begin{bmatrix} (A,p)\\ \psi \\ \lambda \end{bmatrix}
=
\begin{bmatrix} f_J+f_{B_r}\\ 0 \\ 0 \end{bmatrix}.
$$

> **⚠→✅ Знак внешнего 2-блока.** Ранее (по B-1 §6, эвристика «совместной минимизации энергии») было задокументировано `+μ₀W, −C_ΓB, −V_BB`. **Это неверно.** Правильный знак — **`−μ₀W, +C_ΓB, +V_BB`** (весь внешний 2-блок с минусом отн. изолированного `S_ext`): выведен строго из слабой формы как `ψ-строка = (слабое IC1) − (E2)` (см. §10) и **ПОДТВЕРЖДЁН бенчмарком намагниченной сферы `H_in=−M/3`** (`_sphere_probe`, см. §10). Энергетическая эвристика вводит в заблуждение: это задача СОПРЯЖЕНИЯ (седло), а не совместная минимизация по `(A,ψ)`.

- Строка `λ` (тест `μ∈P0`): `+C_{ΓB}^{T}ψ + V_{BB}λ = 0` ⟺ дискретное **(E1)** `Vλ = (K−½)ψ` (та же, что и со знаком −).
- Строка `ψ` (тест `ξ∈P1`): `B_{FΓ}^{T}(A,p) − μ_0 Wψ + C_{ΓB}λ = 0`.
- Дополнение Шура на `ψ` (исключая `λ`) `= −S_ext` ⇒ конденсированная задача `(K + B_FΓ S_ext⁻¹ B_FΓᵀ)\,a = f` — внешняя реакция **ДОБАВЛЯЕТ** жёсткость ⇒ размагничивание.
- Симметрия: диагонали `A_FF, −μ₀W, +V_BB` симметричны, внедиагонали транспонированы. ✅ (Costabel ⇒ самосопряжённость для adjoint фазы E).

## 6. Знак закреплён (была ⚠ → ✅) + остаточные детали

**✅ ЗНАК `C_ΓB` ЗАКРЕПЛЁН: `k_sign=−1`, т.е. `C_ΓB = ½M_PG − Kᵀ` (ветвь `½I−K`).** Реализовано 2026-06-03.

**Дискриминатор (чистый, на ЗАМКНУТОЙ поверхности — хватает куба, сфера для знака НЕ нужна):**
внешняя DtN `S_ext` положительно **определена** (нет ядра констант), т.к. постоянный след `ψ=c` на Γ даёт ненулевой убывающий внешний поток (в отличие от ВНУТРЕННЕЙ DtN, где константы → нулевой поток). Дискретно:

$$A_{\text{int}}\cdot\mathbf 1 = \tfrac12\,\text{areas} - K\cdot\mathbf 1 = \tfrac12\,\text{areas} - (-\tfrac12\,\text{areas}) = \text{areas}\ne 0 \;\Rightarrow\; S_{\text{ext}}\cdot\mathbf 1\ne 0 \;\Rightarrow\; \text{SPD}.$$

Неверный знак `+K` даёт `A_int·1 = ½·areas + (−½·areas) = 0` ⇒ `S_ext·1 = 0` ⇒ паразитное ядро констант (поведение ВНУТРЕННЕЙ DtN). Численно (куб n=2): `−K` → `λ_min(S_ext)=0.22`, `‖S_ext·1‖=1.6`; `+K` → `λ_min=4·10⁻¹¹`, `‖S_ext·1‖=10⁻⁵`. (`hybrid/assembly.py::assemble_exterior_steklov_poincare`, `test_hybrid_steklov.py`.) **Совпадает со строгим выводом (E1):** λ-строка блок-системы даёт `Vλ = −C_ΓBᵀψ = (K−½I)ψ` — ровно (E1). ✓

**✅ (b) `M_ΓΓ = μ₀W` (без дополнительных `K`-членов).** Дополнение Шура блок-системы на `ψ` есть `M_ΓΓ + C_ΓB V_BB⁻¹ C_ΓBᵀ`; подстановка `C_ΓB=½M_PG−Kᵀ`, `V_BB=V` даёт ровно `S_ext = μ₀(W + (½M_PG−Kᵀ)V⁻¹(½M_PGᵀ−K))` ⇒ `M_ΓΓ=μ₀W`, а `K`-члены живут в `C_ΓB`. (Строит этот Шур `assemble_exterior_steklov_poincare`.)

**Остаётся для шага сборки полной блок-системы:**
- (c) размещение `μ₀` (в `M_ΓΓ`/`C_ΓB`/`V_BB`) и подстановка (IC1) vs независимый `λ` — нормировочная деталь; фиксируется при сборке так, чтобы Шур на `ψ` совпал с `S_ext`.
- **Физический бенчмарк (только ВЕЛИЧИНА, не знак):** проницаемая **сфера** в однородном поле `H_in=3μ_out/(μ_in+2μ_out)H₀` — финальная проверка масштаба и новизны (1).

**Готово:** `M_PG` (`assemble_interface_mass`), `S_ext` + знак (`assemble_exterior_steklov_poincare`). **Дальше:** `assemble_coupled_block_system` (внутр. `A_FF,B_FΓ` ⊕ внешн. `V_BB,C_ΓB,μ₀W`) → связанный решатель → сфера/куб/малый outrunner = **предъявление новизны (1)**.

> Примечание: исходно планировались дискретные тождества-произведения Кальдерона (`VW=¼I−K²`) для пиннинга знака, но они требуют аккуратной композиции с масс-обратными (несовпадение пространств P0/P1) и хрупки. SPD-дискриминатор `S_ext` даёт тот же результат строго и проще; тождества-произведения остаются как опциональная глубокая верификация.

## 9. Калибровка интерфейса и нуль-пространство связанной системы (решено 2026-06-03)

Без внешней стенки `n×A=0` связанная система имеет нетривиальное ядро. Полный разбор (закрывает §8.1, §8.3 выше и §8.3 `coupling.md`):

**Размерность ядра = 1 — численно подтверждено** (куб n=1,2: ровно одно `σ≈0`, `SVD`). Единственная мода — **константа множителя `p`**: `(a,p,ψ,λ)=(0,const,0,0)` (т.к. `G·1=0`). Почему больше ничего:
- **Градиенты `A=∇φ`** (ядро curl-curl) — НЕ нуль-моды: связь `Gᵀa=0` их фильтрует (`∫_Ω ∇φ·∇λ_m=0 ∀m ⟺ φ=const`).
- **`ψ=const`** — исключена знаком `−K` (`S_ext` SPD; при `+K` была бы паразитной — дополнительный аргумент за наш знак, §6).
- **Когомологии** — на стягиваемых шаре/кубе отсутствуют; на нестягиваемом outrunner-кольце появятся (гармонические поля: curl-свободные, не градиенты — это **физические** dof, фиксируются разрезами/cuts, НЕ калибровкой) — пункт фазы G.

**Калибровочное пространство множителя: `q∈H¹(Ω)` (полный P1).** Накладывает `∇·A=0` в Ω **и** `A·n=0` на Γ (слабо, из `∫A·∇q=−∫(∇·A)q+∮_Γ(A·n)q`). Обоснование:
1. `H¹` снимает ВСЕ дискретные градиенты; `H¹₀` оставил бы приграничные градиентные моды (тест-функции зануляются на Γ). Численное `dim ker=1` — прямое подтверждение, что `H¹` убрал всё кроме константы `p`.
2. `A·n=0` — **законная калибровка**, не влияет на `B=curl A` (интерфейс связывает `curl A·n=B·n`, а не `A·n`). Чистый калибровочный произвол.
3. Стандарт симметричной FEM/BEM Кулон-калибровки (Hiptmair 2002; Bruckner 2012).

**Снятие константы `p` — вариант A: симметричный бордюр `∫_Ω p=0`** (`hybrid/solver.py`):

$$\begin{bmatrix} M & c\\ c^{T} & 0\end{bmatrix}\begin{bmatrix}x\\ \mu\end{bmatrix}=\begin{bmatrix}b\\ 0\end{bmatrix},\quad c=(0,\,m_p,\,0,\,0),\ m_p[m]=\textstyle\int_\Omega\lambda_m\,dV.$$

Сохраняет симметрию (Costabel ⇒ самосопряжённый adjoint фазы E), масштабируем, **падает явно** при росте ядра (ловит когомологии мотора). `μ≈0` (RHS совместна: ядро ⊥ источнику в a-блоке) ⇒ физика `(a,ψ,λ)` **инвариантна** к калибровке `p`. Численно: `μ=2·10⁻¹⁷`, `‖Mx−b‖=10⁻¹⁴`, `∫p=10⁻¹⁴`.

**Сравнение A (бордюр) vs C (псевдо-обратная / min-norm):** на кубе **идентичная физика** (`Δ(a,ψ,λ)~10⁻¹¹`). A: симметрична + масштабируема + самосопряжённа для adjoint + «громкий отказ» при доп. ядре. C: проще, но плотный SVD не масштабируется и **тихо маскирует** доп. нуль-моды (на моторе занизила бы когомологическую — физическую — компоненту без ошибки → опасно). **Решение: A — решатель; C — независимая SVD-диагностика ядра + кросс-сверка** (подтверждает, что ядро = именно константа `p`, и что бордюр A не искажает физику). Это и есть двойной контроль (`test_hybrid_coupled_solver.py`).

**Ответ на §8.1/§8.3:** `λ` — **независимый множитель** (не подставляем IC1 алгебраически); калибровка `q∈H¹` ⇒ `A·n=0` на Γ; нормировка `μ₀=1` (контраст μ — в `nu`), размерное `μ₀` — отложенный масштабный множитель.

## 10. Знак внешнего блока: вывод из слабой формы + бенчмарк (2026-06-03)

**Строгий вывод `ψ`-строки (test `ξ∈P1`)** как комбинации слабого IC1 и E2 (неизвестные `A,ψ,λ`; `λ=∂_nψ`, `n` наружу из Ω):

- **слабое IC1** (`curl A·n = −λ`, тест `ξ`): `⟨curl A·n + λ, ξ⟩ = 0` ⇒ `B_FΓᵀa + M_PG λ = 0`.
- **E2** (тест `ξ`): `Wψ + (½I+K')λ = 0` ⇒ `W_h ψ + (½M_PG + K_hᵀ)λ = 0`.
- **`ψ`-строка = (слабое IC1) − (E2):**
  `B_FΓᵀa + M_PGλ − W_hψ − (½M_PG+K_hᵀ)λ = B_FΓᵀa − W_hψ + (½M_PG−K_hᵀ)λ = B_FΓᵀa − W_hψ + C_ΓB λ = 0.`
- **`λ`-строка = E1:** `C_ΓBᵀψ + V λ = 0`.

⇒ внешний 2-блок `[[−μ₀W, +C_ΓB],[+C_ΓBᵀ, +V]]`. Дополнение Шура на `ψ` `= −S_ext`; конденсация даёт `(K + B_FΓ S_ext⁻¹ B_FΓᵀ)a = f`.

**Почему энергетическая эвристика ошибается.** Внешняя энергия поля `½⟨S_extψ,ψ⟩>0`, и наивная «совместная минимизация `J(A,ψ)`» даёт `+S_ext` в `ψ`-строке (как было). Но связь FEM(вектор `A`)↔BEM(скаляр `ψ`) через `⟨ψ,curl v·n⟩` — это **задача сопряжения (седло)**, а не совместная минимизация: `ψ` входит как след-множитель, и правильная стационарность — слабая форма выше, дающая `−S_ext`.

**Бенчмарк-арбитр (намагниченная сфера, `H_in=−M/3`, `_sphere_probe`):** прямой перебор знака на собранном операторе (`n=4`):

| вариант внешнего блока | `H_in,z` (точно `−0.3333`) |
|---|---|
| `+μ₀W,−C,−V` (было) | **+1.002** ✗ |
| `−μ₀W,+C,+V` (стало) | **−0.333** ✓ |
| флип только `B_FΓ` | +1.002 (не меняет `a`: `K_eff` чётен по знаку связи) |

**Методический вывод (для защиты):** структурные проверки (симметрия, `Шур=±S_ext`, SPD `S_ext`) НЕ фиксируют относительный знак внешнего блока — его фиксирует **физический бенчмарк**. Поэтому канонический тест (сфера) — обязательная часть предъявления новизны (1), а не «довесок».

## 11. Приложенное однородное поле (расщепление) — бенчмарк 2 (проницаемая сфера)

Однородное поле `H₀` на ∞ НЕ убывает ⇒ нельзя представить убывающим BEM-`ψ`. Расщепление:
`ψ_total = ψ_app + ψ_scat`, `ψ_app=−H₀·x` (известно, энтайр-гармоническое), `ψ_scat→0` (BEM-неизвестная). Известные члены `ψ_app` → правая часть:

- **a-строка (IC2, член берёт `ψ_total`):** `f_a = −B_FΓ ψ_app^Γ`, `ψ_app^Γ[m]=−H₀·x_m` (вершины Γ).
- **λ-строка (E1):** `ψ_scat` сам убывает ⇒ удовлетворяет E1 ⇒ `f_λ = 0`.
- **ψ-строка (= слабое IC1 − E2):** IC1 теперь `curl A·n = H_ext·n = H₀·n − λ_scat` ⇒ слабое IC1 `B_FΓᵀa + M_PGλ = ⟨H₀·n,ξ⟩`; вычет `−E2` (RHS 0) ⇒ **`f_ψ = ⟨H₀·n,ξ⟩ = M_PG·(H₀·n_f)`**.

Восстанавливаемое поле: интерьер `A` — ПОЛНЫЙ (приложенное проникает через связь), `B=curl A`, `H_in=νB`. Реализация: `assemble_coupled_block_system(..., applied_field_h0=H₀)`. Предельный случай `H₀=0` → сводится к §10 (намагниченная сфера). **Аналитика (μ_out=1):** `H_in=3/(μ_r+2)H₀`, `B_in=3μ_r/(μ_r+2)H₀`; `μ_r=1` ⇒ `H_in=H₀` (поле не возмущено — sanity).

## 12. Нестягиваемые области (когомологии/калибровка) — путь A, бенчмарк рамки

Реальный ротор-кольцо — **нестягиваемая** область (`b₁` дырок). Это добавляет нюанс к нуль-пространству.

**Ключевой факт (поправка): в МАГНИТОСТАТИКЕ когомология — это КАЛИБРОВКА, не физический dof.** Гармонические поля `h∈H¹(Ω)`: curl-free + div-free + не градиенты. `A→A+h ⇒ B=curl A` **не меняется** (`curl h=0`) ⇒ B-инвариантны ⇒ калибровочные. (Физическими они были бы только в вихретоковой/заданно-токовой задаче через разрезы — у нас не тот случай.)

**Структура нуль-пространства связанной системы** (численно подтверждено, `test_hybrid_cohomology.py`):
- стягиваемая (куб, `b₁=0`): `dim ker = 1` (константа `p`);
- нестягиваемая (рамка = куб со сквозным отверстием, `b₁=1`): `dim ker = 2` = `1 (const p) + b₁`.
- Лишняя мода — гармоническое поле: `max|curl a|≈1e-14` (B-инвариантна), `aᵀKa≈0` (ядро curl-curl), `|Gᵀa|≈1e-15` (div-free ⇒ Кулонова калибровка её НЕ убирает).

**Следствия для решателя:**
- B **инвариантно** к когомологической компоненте ⇒ **физически верно при любой её фиксации (или без неё).**
- **Поправка к прежнему утверждению «вариант A громко упадёт»:** не обязательно. LU на формально-вырожденной (но СОВМЕСТНОЙ — источник `f_Br` ⊥ curl-free моде, т.к. `∫νB_r·curl h=0`) системе часто решает с малой невязкой, давая НЕ-единственное `A` (произвольная когомологическая компонента), но **правильное `B`**. Это хрупко по числу обусловленности.
- **Робастно:** min-norm (вариант C) — единственное `A⊥ker`, `B` верно; или явные **когомологические cuts** (расширенный симметричный бордюр на `b₁` генераторов — масштабируемо, единственное `A`). Для сетки реального размера dense min-norm не масштабируется ⇒ **cuts — отслеживаемый пункт фазы G**.
- **BEM/экстерьер не страдает:** `∮H·dl=0` в воздухе (нет свободного тока, сцепляющего дырку) ⇒ скалярный `ψ` однозначен.

**Итог пути A:** когомология на нестягиваемых областях разобрана и верифицирована (гармоническая калибровка, `dim ker = 1+b₁`, B-инвариантность). Для реального outrunner-кольца (`b₁=1`): min-norm сейчас, cuts для масштаба; физика (B, момент) не зависит от выбора.
