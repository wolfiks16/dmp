## 3. Детали по ключевым кандидатам

**К1 (ядро).** *Тезис:* нелинейный анизотропный температурно-зависимый магнит B(H,T) с детекцией колена и трекингом необратимого размагничивания на FEM-стороне открытого FEM/BEM-решателя с поэлементной картой риска. *Ближайшее:* модель — Ruoho/Kern/Niu; открытый FEM/BEM — Kielhorn. *Почему открыт:* две литературы разъединены (открытая связка держит магнит линейным; демаг живёт в замкнутом FEM) — подтверждено на US/RU/CN/EU. *Феча vs интеграция:* обе половины заняты по отдельности → защищаема **интеграция**. *Верификация:* MMS + аналитическая нелинейная сфера (есть).

**К2 (комплекс/общность).** *Тезис:* единый магнитостатический+демаг движок с opt-in физикой, **доказанно работающий на разных классах PM-машин** (бесщёточный PMSM и щёточный ДПТ с ПМ ДП25). *Почему защищаемо в 2.4.2:* «электротехнический комплекс + методика + программный комплекс» — прямое попадание в паспорт. *Не наука сама по себе* — носитель К1, но сильное **положение на защиту** и практическая значимость.

**К3 (авиа-рамка).** Yang 2025 делает EM-тепло-демаг авиа-PMSM как **диагностику**; **проектная** оценка в открытой области при реакции якоря+нагреве — зазор. Даёт сертификационную/надёжностную мотивировку К1 именно для БПЛА.

**К4 (adjoint-остаток).** RICAM занял широкий adjoint/TO для PMSM, но **везде фиксированная remanence, без in-loop колена** (робастная TO — без демага/T; электро-тепловая — Br=1.216 Тл, температура как штраф-прокси). Остаток = adjoint сквозь **регуляризованное колено** + бюджет смещения. Узко; не «первый adjoint демага».

**К6 (монолит демаг-тепло — самый интересный «новый» угол).** Слабая связь — дефолт по цене, не по физике. **Тепловой разгон размагничивания** (нагрев → колено вниз → больше потерь/демага → нагрев) — это сильно-связанная нелинейность, которую дефолт не ловит. Высокий импакт для надёжности БПЛА, но дорого/сложно для соло — кандидат в «растяжимую» цель, если К1 закрыт раньше срока.

**К7 (снижение редкозёмов).** Brody занял MnBi low-T ROM; но **методика демаг-робастного снижения редкозёмов** для класса БПЛА на нашей risk-map — стратегически привлекательный прикладной угол (импортозамещение/стоимость). Зависит от доступности данных материалов (возможно — через заказчика).

- **Положение-носитель:** **К2 + К9** (общий отечественный программный комплекс) — сильно для 2.4.2/ВАК, практическая значимость.
- **Вторичные узкие новизны (осторожно):** **К4** (adjoint сквозь колено) и **К5** (conformal как дополнение) — заявлять узко, фиксировать поздно.
- **«Растяжимая» цель / высокий потолок:** **К6** (монолит демаг-тепло) — если темп позволит; самый сильный «новый» научный угол из обзора.
- **Прикладной бонус:** **К7** (снижение редкозёмов) — если будут данные.

## 5. Открытые вопросы (честно, до фиксации новизны)
1. **Полнотекстовый добор CNKI/eLibrary/dissercat** — единственное, что может опровергнуть белое пятно К1/К9 (сейчас absence-of-evidence в US-индексах). Высший приоритет перед защитой.
2. **Conformal vs certified-RB:** если a-posteriori-границы строго сильнее — К5 подавать как model-agnostic дополнение, не как единственную сертификацию.
3. **К4 vs Krenn-Gangl + Egger-Engertsberger:** отличие (негладкость колена в forward-невязке vs оптимизационная негладкость) тонкое — нужен полный текст arXiv:2404.12188 и 2506.01499 для защиты от оппонента.
4. **Общность по классам (К2):** доказать кросс-классовую обобщаемость движка (PMSM + ДП25), а не только на канонических бенчмарках.

## 6. Добор Китай (инлайн-поиск, 2026-06-16) — уточнения к матрице
Цель — закрыть открытый вопрос №1 по китайскому пласту. Англоязычный бэкенд + попытка по иероглифам (полнотекстовые **CNKI/Wanfang недокрыты — caveat**).

- **К1/К9 — белое пятно ДЕРЖИТСЯ в КНР.** Китайский демаг = замкнутый/шаговый FEM; «гибрид» = субдомен-аналитика+FE или Максвелл-Фурье+FE (+ субдомен+DNN-суррогат для PMLSM); внешняя область — усечение или **SBFEM** (масштабир. граничный FEM) на **ЛИНЕЙНЫХ** рассеянных полях. Связки истинный BEM/SBFEM-экстерьер × нелинейный необратимый демаг — НЕТ. Индигенного открытого FEM/BEM+demag ПО для моторов не найдено (рынок — ANSYS/JMAG/Siemens/MotorAnalysis-PM); контекст «Made in China 2025» усиливает ценность К9 (импортозамещение).
- **🔻 К6 ПОНИЖЕН (M, было H): связанная EM-тепло-демаг для SPM — ЗАНЯТО.** Шеффилд/Zhu (Energies 2023, 16(1):131 и 16(6):2516): coupled EM-thermal модульной **SPM**-машины, демаг от PM-поля + якоря + нагрева методом **замороженной проницаемости**, «нагрев ↓Hc, ↑колено → легче необратимый демаг». Ближайший к нашему классу конкурент, но **замкнутый FEM, frozen-permeability post-check, не открытая граница, не in-loop**. Остаток К6 = монолит. сильная связь + открытая граница + in-loop необратимость — **узкий и дорогой**.
- **🔻 К7 ПОНИЖЕН: снижение редкозёмов — ПЕРЕПОЛНЕНО** (феррит-SynRM, гибрид феррит+РЗМ, flux-barrier; IEEE 8002367, обзоры MDPI/ScienceDirect). Самостоятельной новизны нет; только как прикладной сценарий через нашу risk-map.
- **К5: conformal/сертификация в КНР НЕ найдена** (доминируют RSM/BPNN/Monte-Carlo/DFSS — несертифицированные) → узкое белое пятно conformal держится. **NB:** есть китайский **PINN для электромагнетизма PMSM** (Adv. Eng. Informatics 2023) — ещё причина не делать К8 ядром.
- **Итог добора:** **К1/К3 (ядро) и К2/К9 (комплекс/отеч.) — подтверждены сильнейшими; К6 и К7 понижены** (заняты/узки); К4/К5 остаются узкими. Остаточный риск: полнотекстовые CNKI/Wanfang-диссертации не прочитаны — нужен носитель языка/доступ перед защитой.

### Углублённый CNKI/полнотекстовый добор (2026-06-16, по запросам на китайском + WebFetch)
- **Ближайшая угроза К1 ПРОВЕРЕНА И СНЯТА:** PIER-работа по **внешнероторной PMSM** с **гибридом FEA+BEM** (сфетчена) — BEM применён **для скорости расчёта поля, нелинейное/необратимое размагничивание НЕ моделируется, BEM и демаг НЕ объединены** (фокус — cogging-момент/момент через многокритериальную оптимизацию). Даже самый близкий китайский хит держит магнит линейным ⇒ **белое пятно К1 подтверждено на полнотексте**.
- **🔧 КОРРЕКЦИЯ К9 (важно):** в КНР **СУЩЕСТВУЮТ** отечественные (для КНР) мотор-FEM пакеты — **EasiMotor** (自主 IP, 20 типов машин, библиотеки ПМ, потери, х.х./нагрузка/КЗ), **Simdroid** (云道智造, низкочаст. ЭМ: статика/гармон./транзиент, поле-цепь), **ZWSOFT METAS** — но все **FEM, без связки открытый-BEM × необратимый демаг**. ⇒ заявлять надо «нет аналога **связки** открытая граница FEM/BEM + поэлементная карта риска демага», НЕ «нет мотор-ПО». Для РФ-импортозамещения (К9) эти пакеты — зарубежные аналоги, не закрывающие интеграцию.
- **К4 (adjoint):** в КНР параметрическая/топологич. оптимизация ротора PMSM есть (полюс-арка, вспом. пазы, LZJTU 2024), но **adjoint-демаг как метод — европейская тема** (RICAM); китайский adjoint-демаг не выявлен → узкий остаток К4 держится.
- **К5 (conformal):** в КНР conformal prediction / сертификация суррогата для машин **не выявлены** (доминируют Байес-опт., PINN, ROM) → узкое пятно держится.
- **Открытая граница в КНР** = инфинит-элемент (COMSOL, напр. «表贴式永磁电机外围环ования环магnитного поля») или субдоменная непрерывность, **не истинный BEM-экстерьер**. SBFEM — только линейные рассеянные поля.
- **Остаточный caveat:** платные китаеязычные CNKI/Wanfang-диссертации полнотекстово по-прежнему не прочитаны — для финальной защиты желателен носитель языка; но по всему индексируемому и сфетченному **противоречий ядру нет**.
