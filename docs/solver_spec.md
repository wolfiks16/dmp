## 1. Три уровня расчёта (что можно посчитать)

| Уровень | Вопрос | Что нужно задать | Время |
|---|---|---|---|
| **Р1. Магнитостатика** | какое поле, поток, K_e, K_t, момент? | геометрия + материалы + ток | секунды–минуты |
| **Р2. Свойства машины** | момент/угол, потери, КПД, зубцовый момент | + скорость, обмотка | минуты |

## 1а. ПРИНЦИП УНИВЕРСАЛЬНОСТИ: расчёт под ТИП машины, а не под экземпляр

**Требование (Sergey, 2026-08-05):** расчёт должен быть универсальным для **класса машин**, а не настроенным на конкретный двигатель. Конкретная машина = набор параметров, а не отдельный код.

**Это уже частично доказано:** генератор геометрии, написанный под outrunner PMSM, **без единой правки построил ДП25** — щёточный коллекторный ДПТ. Потому что топологически это одно и то же 2D-сечение: *магниты снаружи, зубчатый сердечник внутри*. Различаются не геометрия, а вращающаяся часть, обмотка и способ возбуждения.

### Что универсально, а что зависит от типа

| Слой | Зависит от типа? | Состав |
|---|---|---|
| **Физическое ядро** | **НЕТ** — пишется один раз | материалы B(H,T)/B(H); необратимый демаг (защёлкивание); нелинейный решатель поля; тепловая задача; связка; потери (Штейнмец, вихревые, скин); Тейлор-зазор |
| **Слой типа машины** | **ДА** | генератор геометрии (топология); модель обмотки; формула K_e/момента; система отсчёта для потерь |

⇒ Новую машину добавляем, описав **только второй слой**; физика не трогается. Это и есть «общность комплекса».

### Универсальное описание геометрии — радиальный стек слоёв

Вместо жёсткого «outrunner» — список слоёв изнутри наружу, каждый со своей ролью:

```
слои = [ (вал),  (ярмо),  (зубцы+пазы),  (зазор),  (магниты),  (ярмо) ]   ← ДП25 и outrunner PMSM
слои = [ (вал),  (ярмо),  (магниты),     (зазор),  (зубцы+пазы), (ярмо) ] ← inrunner PMSM
```

Плюс флаги топологии:

| Параметр | Значения | Что задаёт |
|---|---|---|
| **вращается** | наружная часть / внутренняя | outrunner vs inrunner vs щёточный (вращается якорь) |
| **магниты на** | роторе / статоре | PMSM vs щёточный ДПТ с ПМ |
| **исполнение магнитов** | поверхностные / встроенные / спицевые | SPM, IPM, spoke |

### Слой обмотки — подключаемый

| Тип | Задаётся | Как считается ток в пазах | Как считается K_e |
|---|---|---|---|
| **3-фазная распределённая** | витков/паз, схема «звезда пазов», коэфф. заполнения | по фазам и углу вектора тока γ | из потокосцепления фаз: K_e = p·λ_m, K_t = 1.5·p·λ_m |
| **Коллекторная (волновая/петлевая)** | Z проводников, число ветвей a, шаги по пазам и коллектору | распределение под полюсами (коммутация) | K_e = p·Z·Φ/(2π·a), K_t = K_e |

Обе получают **поток из одного и того же полевого решения** — различается только пост-обработка.

### Система отсчёта для потерь — выбирается по топологии

Критично и легко ошибиться: вихревые потери считаются в системе **той части, где лежит материал**.

| Тип машины | Магниты | Их «видит» пульсация | Считать в системе |
|---|---|---|---|
| PMSM (магниты на роторе) | вращаются | зубцовая от статора | **ротора** (со-вращающиеся точки) |
| **Щёточный ДПТ (магниты на статоре)** | **неподвижны** | зубцовая от вращающегося якоря | **статора** |

Ошибка выбора системы даёт фантомные потери от постоянного поля магнита.

### Что ещё требуется для универсальности

1. **Материалы по регионам** (уже понадобилось на ДП25: якорь — электротехническая сталь, корпус — Ст10). Штатный слой пока берёт одну кривую на всё железо.
2. **Число полюсов и пазов — свободные параметры** (12/14 и 13/4 уже проверены; 13 пазов — нечётное, что нормально для коллекторной).
3. **Библиотека типов** с эталонным примером на каждый: для щёточного ДПТ эталон уже есть — **ДП25 с паспортом ТУ** (валидация −3.5 % по сопротивлению, +7.8 % по K_e).

### Зачем это диссертации

Универсальность по типу — **носитель новизны К2/К9** («отечественный программный комплекс с единым физическим ядром»). Утверждение «один движок считает и бесщёточный PMSM, и щёточный ДПТ» подкреплено фактом: **ДП25 посчитан тем же кодом, что и PMSM**, и сверен с сертифицированным ТУ.

### 2.1. Геометрия сечения

| Параметр | Ед. | Примечание |
|---|---|---|
| Число пазов, число полюсов | — | 12/14 (PMSM), 13/4 (ДП25) |
| Радиус расточки | мм | |
| Толщина ярма статора | мм | |
| Радиальная длина зубца/паза | мм | |
| **Воздушный зазор** | мм | ⚠ см. §5 — требует измельчения сетки |
| Толщина магнита | мм | |
| Толщина ярма ротора/корпуса | мм | |
| Доля зубца в зубцовом шаге | — | 0…1 |
| Охват полюса магнитом | — | 0…1 |
| Осевая длина (пакет) | мм | |
| Скос пакета | град | опц., даёт коэффициент скоса |

### 2.2. Материалы

**Магнит** (задаётся как ДАННЫЕ, не «модель»):
| Параметр | Ед. | Откуда |
|---|---|---|
| B_r, H_cB, H_k (колено), H_cJ при T₀ | Тл, А/м | **этап A опыта** / datasheet / ГОСТ |
| α_Br, γ_Hc | %/°C | этап A |
| μ_rec | — | этап A |
| σ(T) — электропроводность | См/м | для вихревых потерь |
| Плотность, теплопроводность, теплоёмкость | | |
| Число сегментов N_seg | — | **решающий фактор** (потери ∝ 1/N²) |

**Сталь** — отдельно для якоря/статора и для корпуса/ротора:
| Параметр | Откуда |
|---|---|
| Кривая B(H) (таблица) | datasheet или измерение. ⚠ **обязана доходить до насыщения** (§5) |
| Удельное сопротивление, плотность | справочник/datasheet |
| Коэффициенты потерь: k_гист, α, толщина листа | таблица удельных потерь; **вихревой коэффициент выводится из ρ и толщины аналитически** |
| **Шихтованная или МАССИВНАЯ** | массив → модель сплошного тела со скин-пределом |
| Теплопроводность, теплоёмкость | справочник |

**Медь:** ρ₀, температурный коэффициент, коэффициент заполнения паза.

### 2.3. Обмотка и режим
| Параметр | Примечание |
|---|---|
| Витков на паз / схема | 3-фазная (PMSM) или коллекторная (Z проводников, число ветвей) |
| Ток (амплитуда) | ⚠ **два разных**: мгновенный для поля, СКЗ для потерь |
| Угол вектора тока γ | 0 = worst-case d-ось (демаг), π/2 = q-ось (момент) |
| Частота вращения | задаёт электрическую частоту и потери |
| Напряжение питания U | для режима с ограничением по напряжению |
| Множитель ШИМ | 1.0 (синус) или ~2.0 (реальный инвертор) |

### 2.4. Тепловые условия
| Параметр | Примечание |
|---|---|
| Температура среды | worst-case: горячий отсек/замачивание |
| **h наружной поверхности** | обдув винта: 15–25 (зависание) … 50–150 (полёт) |
| **Охлаждение статора** | кондукция в раму (T рамы) — **не** конвекция в стоячий воздух |
| Предел по температуре | класс изоляции (F=155, H=180 °C) |
| Горизонт и шаг по времени | ⚠ шаг ≤ 0.5 с (см. §5) |

## 3. ВЫХОДНЫЕ ПАРАМЕТРЫ

### 3.1. Поле и магнитная цепь (Р1)
- карта индукции **B** [Тл] и линии потока по сечению;
- **поток на полюс Φ** [Вб], индукция в зазоре [Тл];
- **K_e — коэффициент противо-ЭДС** [В·с/рад] (сколько вольт даёт двигатель на единицу скорости; = мера силы магнитной системы; падает при размагничивании) и эквивалент **kV** [об/(мин·В)];
- **K_t — коэффициент момента** [Н·м/А] (сколько момента даёт единица тока);
- насыщение по регионам: среднее и максимальное **B** в зубцах, ярме, корпусе [Тл].

### 3.2. Характеристики машины (Р2)
- **момент** [Н·м] (Арккио по зазору), зависимость от угла ротора, **пульсации**;
- зубцовый момент (при нулевом токе);
- **потери**: медь, сталь статора, сталь ротора, вихревые в магните — раздельно;
- **КПД**;
- **под ограничением напряжения**: ток, обороты, момент, мощность;
- **тяга** (при токовом ограничении **∝ моменту**; винт: τ=kω² ⇒ тяга ∝ ω² ∝ τ).

### 3.3. Тепло и демаг (Р3 — ядро)
- поле температур; **T магнита**, **T обмотки** (обычно она — узкое место);
- траектории T(t), потерь, запасённой энергии;
- **карта риска размагничивания** по ячейкам: запас до колена H_k [А/м] (отрицательный = за коленом) и доля сохранённой ремнантности **r** (1.0 = цел, 0.8 = необратимо потеряно 20 %);
- **необратимая потеря** по магниту: минимальная и средняя **r**;
- **падение K_e и момента** [%] — инженерное следствие («мотор стал слабее на …%», навсегда, до замены магнитов);
- **режимы отказа**: тепловой разгон (T за предел) / каскад саморазмагничивания (ячейки ниже H_cJ) с указанием причины;
- время выхода на установившийся режим.

### 3.4. Проверки достоверности (выдаются ВСЕГДА)
| Проверка | Норма |
|---|---|
| Сошлась ли нелинейная итерация | обязательно `да` + число итераций и достигнутая невязка |
| **Энергобаланс** (запас/источник/отвод) | невязка ~1e-14 |
| Порог теплового разгона s_crit | и с какой стороны от него режим |
| Сходимость по шагу времени | \|T(dt) − T(dt/2)\| < ~2 °C |
| Разрешение зазора | ≥3 элемента поперёк |

⚠ **Расчёт без этих отметок считать непригодным для отчёта.**

## 4. ЛОГИКА РАСЧЁТА (порядок)

```
1. ГЕОМЕТРИЯ И СЕТКА
   параметры сечения → сетка; измельчение: зазор ≥3 элем., магнит и зубцы мельче
   ПРОВЕРКА: разрешение зазора; замкнутость слоёв

2. МАТЕРИАЛЫ ПО ЯЧЕЙКАМ
   регион → своя ν(B): воздух=1, магнит=1/μ_rec, сталь якоря / сталь корпуса — СВОИ кривые
   ПРОВЕРКА: кривые доходят до насыщения (μ_r последнего сегмента < 2)

3. ПРЕДВЫЧИСЛЕНИЕ ПОТЕРЬ ЯДРА          [для Р3]
   свип по положению ротора при рабочем токе/скорости →
     • сталь статора: волна B в НЕПОДВИЖНЫХ точках → Штейнмец
     • ротор-сторона: поле в СИСТЕМЕ РОТОРА (со-вращающиеся точки) →
         вихревые магнита (σ, ширина сегмента, ×ШИМ)
         сталь ротора (массив → сплошное тело со скин-пределом; шихтовка → Штейнмец)
   → карта тепловыделения [Вт/м³], замороженная на тепловом шаге

4. ШАГ ПО ВРЕМЕНИ (n = 1…N)            [Р3; для Р1/Р2 — один проход без п.4-5]
   4.1 T ячеек → свойства: B_r(T), H_cJ(T), колено H_k(T), ρ_меди(T)
   4.2 МАГНИТНАЯ ЗАДАЧА (итерация Пикара до сходимости):
         ν и источник ν·B_r ← текущее состояние магнита
         решить −div(ν∇A_z) = J_z + curl(νB_r)
         B = curl A_z; H = νB − νB_r
         рабочая точка магнита H_∥ → кандидат ремнантности r_now
         r_эфф = min(r_защёлкнутое, r_now)   ← НЕОБРАТИМОСТЬ В ТОЙ ЖЕ ИТЕРАЦИИ
         повторять до сходимости по B
   4.3 ЗАЩЁЛКНУТЬ: r ← min(r, r_эфф)         ← история, путь важен
   4.4 ПОТЕРИ: медь ρ(T)·J² + карта ядра из п.3
   4.5 ТЕПЛОВОЙ ШАГ (неявный Эйлер): (C/dt+K+R)T' = ...
   4.6 ПРОВЕРКИ ОСТАНОВА:
         T за пределом → ТЕПЛОВОЙ РАЗГОН (результат, не ошибка)
         ячейки ниже H_cJ → КАСКАД (равновесия не существует)
         |dT/dt| мало → установившийся режим
   4.7 если магнитная задача не сошлась — повторить шаг мельче по T (2,4,8… подшага),
       откатив состояние; не помогло → каскад

5. ПОСТ-ОБРАБОТКА
   K_e, K_t, момент при конечном состоянии; КПД со всеми потерями; тяга;
   карта риска; падение K_e; энергобаланс; отчёт по проверкам п.3.4
```

### Ключевые правила (нарушение = неверный результат)
1. **Необратимость учитывается ВНУТРИ итерации поля** (п. 4.2), а не после — иначе это «демаг пост-хок», как у соседей по prior-art.
2. **Ток для поля ≠ ток для потерь** (мгновенный worst-case vs СКЗ с поправкой на заполнение паза).
3. **Ротор-сторона считается в системе РОТОРА** — иначе вращающееся постоянное поле магнита даст фантомные вихревые потери.
4. **Массивные детали ≠ шихтованные**: удельные Вт/кг Штейнмеца применимы только к листу; для массива — сплошное тело со скин-пределом.

## 5. ГРАНИЦЫ И ЛОВУШКИ (проверено на практике)

> **Полный реестр — [`pitfalls.md`](pitfalls.md)** (78 записей на 2026-09-10: как проявилось → почему → правило → где закреплено). Таблица ниже — краткая выжимка самых частых ловушек расчёта. Новые ловушки дописываются в реестр, не сюда.

| Ловушка | Признак | Лечение |
|---|---|---|
| **Зазор тоньше элемента сетки** | итерация не сходится; поле в зазоре бессмысленно | измельчить **зазор** (не всю сетку) до ≥3 элементов |
| **Кривая B(H) обрывается до насыщения** | скачок проницаемости на границе таблицы → развал итерации | продолжить таблицу до μ_r→1 (проверка автоматическая) |
| **Глубокое насыщение железа** | Пикар осциллирует или застревает | сильная недорелаксация (до ω≈0.05); **диагностировать по истории невязки**, не подбирать вслепую |
| «Похоже на ответ» ≠ «сошлось» | невязка застряла на 1e-2, а поле выглядит правдоподобно | всегда смотреть флаг сходимости и невязку |
| **Грубый шаг по времени** | траектория меняется при dt/2 | dt ≤ 0.5 с (проверено) |
| 2D не видит торцевых эффектов | завышение K_e на 5–15 % на малых машинах | учитывать при сверке с натурой; не подгонять параметры |
| Каскад | остановка расчёта | **это результат** (граница применимости), не отказ; момент срыва зависит от дробления шага — не трактовать как предсказание |

## 6. ЧТО НУЖНО ДЛЯ САМОСТОЯТЕЛЬНОЙ РАБОТЫ (техзадание на слой)

Сейчас расчёт запускается написанием скрипта. Чтобы считать самостоятельно, нужен слой:

1. **Один файл конфигурации** (тип машины + геометрия + материалы + режим + тепловые условия + численность) — человекочитаемый, с единицами и источником каждого значения (требование §12: пред-регистрация условий).
2. **Библиотека материалов**: магниты (свои измеренные SmCo, N42SH, КС25ДЦ-240, N35), стали (Ст10, M270) — выбор по имени.
3. **Библиотека ТИПОВ машин** (§1а): outrunner SPM PMSM, inrunner PMSM, щёточный ДПТ с ПМ, спицевой — каждый со своим слоем «геометрия + обмотка + K_e + система отсчёта потерь» и **эталонным примером для проверки** (для щёточного ДПТ эталон — ДП25 с паспортом ТУ).
4. **Запуск одной командой** с выбором уровня Р1/Р2/Р3.
5. **Отчёт**: числа + карты + **обязательный блок проверок** (§3.4); отказ выдавать результат, если проверки не пройдены.
6. **Свипы**: по току, температуре среды, материалу — с сохранением всех точек (для карт и crossover).
7. **Анализ чувствительности** — встроенный, по списку плохо известных параметров.

Порядок реализации предлагается такой же, как физика строилась: сначала конфиг+библиотека+Р1 (можно проверить на ДП25), затем Р2, затем Р3 и свипы.
