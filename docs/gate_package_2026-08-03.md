## Резюме новизны (одноядерная конструкция)
- **Ядро:** **НН-1** — самосогласованный связанный магнитотепловой расчёт с необратимым размагничиванием в петле итерации + разгон/каскад [**ПОСТРОЕНО в 2D**]; **НН-2** — методика вердикта выбора магнитного материала (SmCo↔NdFeB) как **вычисленного crossover** [ядро есть, слой-вердикт будет].
- **Носители:** НН-3 сертиф. суррогат + conformal prediction; НН-4 adjoint (узко); отечественный комплекс; SmCo своими магнитами.
- **Снято из новизны:** «открытая область» (BEM открыт по определению — не вклад); «модель SmCo» (тот же аппарат `B(H,T)`, что у NdFeB — отличие в параметрах).

## Резюме физики ([`coupled_problem.md`](math/coupled_problem.md))
- Связанная задача: магнитоквазистатика (планарная A-постановка) + нестационарная теплопроводность, **двусторонняя связь** через температурно-зависимые свойства и полевые источники тепла.
- Необратимый демаг = **внутренняя переменная состояния** (гистерезис рекойл-типа, защёлкивание) ⇒ зависимость от истории.
- **Самосогласованность** = неподвижная точка связанного оператора (3 уровня: поле↔демаг монолитно; магнит↔тепло staggered; стационар).
- **Полная модель тепла (B-full):** медь $\rho(T)$ + сталь статора/ротора Штейнмец + **вихревые магнита из $\partial_t\mathbf B$**; дифф. ГУ ($h_{\text{out}}$ обдув / $h_{\text{in}}$ статор→рама кондукцией); зазор $k_{\text{eff}}(n)$ по Тейлору; $f\approx817$ Гц при $n=7000$ об/мин.
- **Разгон** = потеря устойчивости стационара (порог $s_{\text{crit}}$); **каскад** = несуществование квазистат. равновесия.

## Ключевые решения — на одобрение научрука
1. **Одноядерная новизна (К6′)**; SmCo-переформулировка (методика выбора материала, НЕ модель); «открытая область» снята.
2. **Путь A+B-full** (полный первопринцип тепла: собственные потери магнита/ротора + горячая среда) + **режим напряжения** для деградации характеристик машины ($R(T)\uparrow$ + $K_t\downarrow$).
3. **Огибающая worst-case** (d-ось + горячая среда/замачивание) — обоснование: heavy-lift/зависание (обдув слаб, замачивание), deep-research по тепловой среде БПЛА.
4. **Границы 2D приемлемы:** нет осевого отвода/торцевого воздуха; внешний/внутренний воздух — ГУ, не меш (стандартная практика).
5. **Методология достоверности** (§12): пред-регистрация условий + источники, контролируемый эксперимент (различается только материал), свип не точка, публикация нулевого результата, верификация ⟂ сценарию, валидация, чувствительность с полосой неопределённости.

## Открытые вопросы / нужны решения и данные
- **Данные для B-full:** коэффициенты Штейнмеца M270; $\sigma_{\text{pm}}(T)$ SmCo/NdFeB; число сегментов магнита $N_{\text{seg}}$; $T_{\text{frame}}$ крепления; рабочее напряжение $U$.
- **Режим напряжения** включать в первую статью или как follow-up?
- **Глубина строгости:** каскад как вариационное неравенство? полнотензорная $\nu$ за коленом? (§11 открытые пункты).
- **Prior-art риск:** сверить CNKI/китайскую литературу по SmCo-высокотемп. + связанный тепло-демаг (недокрыто US-поиском) — для защиты НН-2.

## Что просим у научрука
Одобрить (или поправить): **(1)** формулировки новизны, **(2)** постановку тепла + источники + ГУ + разгон/каскад, **(3)** методологию достоверности. После одобрения — реализация B-full по кускам с оракулами → перегон харвеста (dt≤0.5, T_cap) → статья 1.
