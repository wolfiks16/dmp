# Оформление рисунков — эталон

> Канонический пример: `docs/papers/experiments/fig_knee_loadline.py` → `figs/fig_knee_loadline.png`.
> Все новые рисунки диссертации, статей и докладов делаются по этому образцу.
> Дата: 2026-08-27.

---

## 1. Данные — только из модели

- Кривые и точки **берутся из расчёта** (`magnet.curve_at(T)`, результат решателя), **никогда не рисуются от руки**. Рисунок не имеет права разойтись с решателем.
- **Все числа в подписях подставляются форматированием** из тех же переменных, что и график. Вписанное руками число протухает при следующем прогоне.
- Скрипт-генератор лежит **в репозитории** рядом с выходом (`figs/`), а не в scratchpad.
- Сохранение: `dpi=200`, `facecolor="white"`, `bbox_inches="tight"`.

## 2. Палитра (фиксированная)

| Константа | HEX | Смысл |
|---|---|---|
| `DARK` | `#1F2A38` | текст, стрелки процесса |
| `STEEL` | `#2E6C99` | холодное / базовое / исходное состояние |
| `HEAT` | `#E1442F` | горячее / опасное / конечное состояние |
| `GREEN` | `#2FA36B` | безопасно |
| `AMBER` | `#E8A33D` | пограничное |
| `MUTED` | `#5A6B7B` | служебные линии, оси, вспомогательное |

Шрифт — `DejaVu Sans` (кириллица): `plt.rcParams["font.family"] = "DejaVu Sans"`.

## 3. Заголовки

- **Общий заголовок — это ВЫВОД предложением, а не название.**
  ✅ «За колено магнит уходит не потому, что поле выросло, — а потому что КОЛЕНО ДОГНАЛО точку»
  ❌ «Кривые размагничивания при разных температурах»
  `fig.suptitle(..., fontsize=15, fontweight="bold", color=DARK)`
- Кадры подписаны **«(а) …», «(б) …»**, `fontsize=13.5, fontweight="bold"`, коротко.

## 4. Два кадра: общий вид + увеличение

Когда нужны и полная картина, и деталь — **не жертвовать ни тем, ни другим**:

- в общем кадре — пунктирная `Rectangle` вокруг зоны увеличения;
- `ConnectionPatch` от **правых** углов рамки к **левым** углам второго кадра (`ls=":"`, `lw=1.1`, `alpha=0.75`);
- ⚠ с `ConnectionPatch` **`tight_layout` не работает** — компоновать `fig.subplots_adjust(...)`.

## 5. Оси

- Полное название величины + обозначение + единица: **«Напряжённость магнитного поля  H, кА/м»**, **«Индукция  B, Тл»**. `fontsize=13`.
- Никаких пояснений-стрелок в подписи оси («← сильнее поле») — это шум.
- Спайны `top`/`right` убрать, `left`/`bottom` — цветом `MUTED`.

## 6. Легенда — минимум

- **2–3 записи максимум**, короткие. **Без скобок и без пояснений после запятой.**
  ✅ «B(H) — по индукции»  ❌ «B(H) — по индукции («нормальная»), нуль на H_cB»
- Легенда различает **стиль линии** (сплошная / пунктир) — через прокси-хэндлы `Line2D` цветом `MUTED`. Вариант/температура различается **цветом** и подписывается **прямо у конца кривой** (`20 °C`, `150 °C`), а не в легенде.
- Фон обязателен, иначе сливается: `frameon=True, facecolor="white", edgecolor="none", framealpha=0.92`.

## 7. Подписи на поле графика

- Только **короткие ярлыки**: «колено», «нагрев», «реакция якоря». Объяснения — под рисунок.
- У каждой подписи **белая полупрозрачная подложка**, иначе текст лезет на линии:
  `WBOX = dict(facecolor="white", edgecolor="none", alpha=0.9, pad=1.8)`
- Ключевые точки — **крупные кружки** `ms=17…18`, белая обводка `mec="white", mew=1.9`, номер белым внутри.
- Стрелки процесса: `color=DARK, lw=2.6, arrowstyle="-|>"`; второй шаг — пунктиром + `connectionstyle="arc3,rad=0.18"`.
- Зоны смысла: `axvspan(..., alpha=0.07)` цветом смысла + короткая подпись, повёрнутая на 90° у края.

## 8. Расшифровка — ПОД рисунком, не на нём

Пронумерованные точки ①②③ объясняются подписью под рисунком (`fig.text`, `fontsize≈12.4`, `linespacing≈1.75`), 2–4 короткие строки. Под неё резервируется место: `subplots_adjust(bottom≈0.20)`.

## 9. Терминология

- **Только русские термины**, никаких англицизмов-калек (было «интринзик» → стало «по намагниченности»).
- Каждый параметр расшифрован словами; сокращения, понятные только автору, запрещены — см. `docs/glossary.md`.

**Правило проверки перед сдачей:** посмотреть на рисунок глазами человека, который видит его впервые и не читал текст. Если что-то требует пояснения — либо подписать, либо убрать.
